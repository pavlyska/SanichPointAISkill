# 🤖 SanichPoint AI Skill

Официальный AI-скилл и системная инструкция для генерации интерактивных презентаций в формате **SanichPoint**.

## 📁 Структура
* **SKILL.md** — файл скилла для AI-ассистентов (**ChatGPT, Claude, Cursor, Antigravity, GitHub Copilot, DeepSeek**).

## 🚀 Как использовать
1. Скопируйте содержимое SKILL.md в системный промпт нейросети, либо подключите как Skill/Rule в вашей среде разработки (Cursor / Antigravity / Claude Code).
2. Задайте тему: *«Сделай презентацию для SanichPoint на тему [Ваша тема]»*.
3. Нейросеть сгенерирует компактный блок SANICHPOINT_AI.
4. Вставьте этот код в приложение **SanichPoint** через кнопку **«✨ AI Презентация»**.
