# 📽️ SanichPoint Studio — AI Presentation Skill

Официальное руководство пользователя по работе с AI-скиллом для генерации интерактивных, кинематографичных презентаций в формате **SanichPoint**.

---

## 📖 Что это такое?

**SanichPoint** — это студия создания интерактивных презентаций в формате единого автономного HTML-файла (работает в любом браузере без серверов и зависимостей).

Файл **`SKILL.md`** в этом репозитории содержит системные директивы, правила верстки и эстетические стандарты студии. Когда нейросеть (**ChatGPT, Claude, DeepSeek, Antigravity, Cursor, Copilot**) изучает этот скилл, она мгновенно создает презентации профессионального уровня в ультракомпактном формате `SANICHPOINT_AI`.

---

## 🚀 Пошаговое руководство для пользователя

### Способ 1: В веб-версии ChatGPT / Claude / DeepSeek

1. Откройте файл [**SKILL.md**](./SKILL.md) и скопируйте весь его текст.
2. Вставьте текст скилла в поле **Custom Instructions / System Prompt** нейросети (или просто отправьте первым сообщением в новый чат).
3. Напишите ваш запрос, например:
   > *«Сделай презентацию для SanichPoint на тему: История создания квантовых компьютеров»*
   > *«Сделай доклад для SanichPoint про Петра I с акцентом на реформы флота и металлургии»*
4. Нейросеть вернет один компактный блок кода `SANICHPOINT_AI` (~40–80 строк).
5. Запустите приложение **SanichPoint.exe**, нажмите кнопку **«✨ AI Презентация»** (или «Вставить ИИ»), вставьте код и нажмите **«Применить»**.
6. Презентация мгновенно развернется в редакторе! Вы можете отредактировать любой слайд вручную, сменить фон, подвигать элементы 1-к-1 и нажать **«Экспорт HTML»**.

---

### Способ 2: В AI-ассистентах и средах разработки (Cursor, Antigravity, Claude Code)

Если этот репозиторий открыт у вас в IDE, скилл уже зарегистрирован:
* В **Antigravity IDE**: скилл подключен как `sanichpoint`. Просто напишите агенту:
  > *«Сделай доклад для SanichPoint на тему: Эпоха индустриализации»*
* В **Cursor** или **Claude Code**: укажите файл скилла через `@SKILL.md`:
  > *«По правилам @SKILL.md сгенерируй презентацию про запуск первой орбитальной станции»*

---

### Способ 3: По ссылке на GitHub

Если вы общаетесь с нейросетью, умеющей читать веб-страницы и репозитории:
> *«Изучи правила и формат из файла SKILL.md по этой ссылке и сделай презентацию про космическую программу "Буран"»*

## 🎨 Шпаргалка по возможностям формата `SANICHPOINT_AI`

### 1. Темы оформления (`THEME`)
Задаются в заголовке презентации (`THEME: ...`):
* `ruby` — лидеры, геополитика, военная история, революции, державные темы.
* `gorkygold` — классическая культура, история XIX–XX века, мемуары, архитектура.
* `sapphire` — госуправление, право, цифровизация, наука, дипломатия.
* `emerald` — экономика, инвестиции, экология, медицина, природные ресурсы.
* `amethyst` — философия, космос, искусство, психология, социология.
* `cyan` / `cyberpunk` — IT, искусственный интеллект, стартапы, футуризм.
* `titanium` / `titan` — тяжелая промышленность, инженерия, металлургия, ВПК.

---

### 2. Индивидуальные фоны каждого слайда (`BG`)
Тег `BG` задается в начале каждого слайда:
* **Градиенты**: `BG: gradient | deep-space`
  *(доступны пресеты: `deep-space`, `midnight-blue`, `golden-glow`, `emerald-night`, `cyber-violet`, `crimson-sunset`, `slate-modern`, `dark-radial` или произвольный CSS `linear-gradient(...)`)*.
* **Узоры и сетки**: `BG: pattern | dots | #0B0F19`
  *(типы узоров: `dots` — микроточки, `grid` — сетка, `blueprint` — синий чертёж, `radial` — мягкий фокус)*.
* **Полноэкранное фото**: `BG: image | https://.../photo.jpg | 0.65`
  *(ссылка на фото + уровень затемнения от 0.0 до 1.0 для четкости текста)*.
* **Сплошной цвет**: `BG: color | #0A192F`

---

### 3. Компоновки слайдов (`LAYOUT`)
* `LAYOUT: right-image` — контент слева (51%), крупное фото справа (38%).
* `LAYOUT: left-image` — зеркальный слайд: фото слева, контент справа.
* `LAYOUT: split` — две равные колонки по 44% (для сравнений «Было / Стало»).
* `LAYOUT: cards` — горизонтальная сетка из 2–3 карточек или метрик в ряд.
* `LAYOUT: center` — монументальный контент по центру экрана.
* `LAYOUT: quote-hero` — акцентный блок цитаты по центру с крупной типографикой.

---

### 4. Новые выразительные компоненты
* **Метрика / KPI**:
  `METRIC: +140% | Прирост эффективности | Рекордный показатель за 12 месяцев`
* **Таймлайн / Этап**:
  `TIMELINE: ЭТАП 01 | Старт реформ | Принятие базового пакета законов`
* **Акцентная выноска (Callout)**:
  `CALLOUT: ! | Важный вывод | Ключевой фактор устойчивости | accent`
  *(стили: `accent`, `warning`, `danger`, `success`, `info`)*
* **Окно терминала / Код**:
  `CODE: deploy.sh | BASH | docker compose up -d`
* **Неоновый разделитель**:
  `DIVIDER: РАЗДЕЛ I • СТРАТЕГИЧЕСКИЙ АНАЛИЗ`
* **Кнопка-ссылка**:
  `BUTTON: Изучить отчет в деталях -> | https://example.com | ->`

---

### 5. Точные координаты элементов (`POS` и `@ x, y, w`)
Вы можете попросить нейросеть (или задать вручную) точные координаты любого элемента на 16:9 холсте (`x`, `y`, `w` в процентах от 0 до 100):
* Инлайн: `CALLOUT: ! | Вывод | Текст | accent @ 4, 62, 44`
* Отдельной строкой:
  ```text
  POS: 52 | 60 | 44
  CALLOUT: ! | Вывод | Текст | accent
  ```
* Свободный режим: `LAYOUT: custom` (каждый элемент встает на свои координаты).

## 💡 Советы для идеального результата

1. **Фотография на каждом слайде**: Скилл требует, чтобы каждый слайд содержал смысловое фото (`IMAGE`), заданное без сжатия по высоте (только `@ x, y, w`), используя 7 Золотых Архетипов верстки.
2. **Просите разнообразие**: Укажите нейросети желаемое настроение: *«Сделай драматичный доклад с контрастными фонами (градиенты и чертеж), метриками и таймлайном»*.
3. **Проверяйте ссылки на фото**: Нейросеть должна использовать прямые ссылки на графические файлы (например, из Wikimedia Commons `upload.wikimedia.org/...`), а не ссылки на веб-страницы описания картинок.
4. **Редактирование 1-в-1**: Любой сгенерированный слайд в SanichPoint можно свободно передвигать, менять тексты, масштабировать карточки и экспортировать готовый шедевр в один клик.
